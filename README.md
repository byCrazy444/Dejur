# 🏫 График и Журнал Дежурств — Класс A-2

Интерактивный веб-сайт для ведения учёта дежурств учеников **Класса A-2** на период с **02.10.2026** по **31.12.2026** (только учебные дни, без выходных суббот и воскресений).

---

## 🚀 Как открыть сайт
1. Откройте файл `index.html` в любом современном браузере (Google Chrome, Microsoft Edge, Mozilla Firefox, Yandex Browser, Safari).
2. Сайт полностью автономен, не требует сервера, Node.js или подключения к интернету.

## ✨ Основные возможности сайта

### 1. 📋 Сводная таблица (Журнал дежурств)
- Двумерная интерактивная таблица: строки — ученики, столбцы — даты.
- **Закрепленные колонки (Sticky):** ФИО учеников и заголовок дат остаются на месте при прокрутке.
- **Чистая таблица и простые статусы:**
  - Исходно таблица абсолютно пустая — нет никаких лишних служебных отметок.
  - Только понятные и наглядные статусы: `✓ Дежурил`, `✗ Не дежурил`, `— Уважительная причина`.
- **Быстрая отметка:** 
  - **Один клик на ячейку** переключает статус по кругу: `✓ Дежурил` &rarr; `✗ Не дежурил` &rarr; `— Уважительная причина` &rarr; `Очистить`.
  - **Двойной клик или правый клик** открывает всплывающее окно для выбора точного статуса и добавления текстовой заметки (например: *"мыл доску"*, *"заболел"*, *"замена"*).
- **Кнопка сохранения:**
  - Кнопка **«💾 Сохранить»** в верхней панели — сохраняет состояние в браузере с отображением времени сохранения.
- **Кнопка «📍 Сегодня»:**
  - Нажатие на оранжевую кнопку **«📍 Сегодня»** плавно прокручивает таблицу прямо к сегодняшнему учебному дню.
  - Текущая дата подсвечивается ярким бейджем «Сегодня» и мягким акцентным фоном.
- **Фильтрация:** по месяцам (Октябрь, Ноябрь, Декабрь или Все 65 дней).
- **Живой поиск:** моментальный поиск по фамилии или имени.

### 2. 📅 Дежурные по дням (Дневной режим)
- Просмотр дежурных на выбранный день.
- Переключение дат стрелками `‹ Предыдущий` / `Следующий ›` или через календарь.
- Карточки дежурных с кнопками фиксации:
  - `✓ Дежурил`
  - `✗ Не явился`
  - `— Уважительная причина`
  - `✏️ Заметка` и `✕ Снять отметку`.
- Возможность быстро отметить любого ученика на этот день.

### 3. 📊 Рейтинг и статистика
- Вкладка со статистикой по каждому из 21 ученика:
  - Сколько раз дежурил (зеленый счетчик).
  - Сколько пропустил (красный счетчик).
  - Количество уважительных причин.
  - Процент исполнительности с наглядной шкалой прогресса.
  - Дата последнего дежурства.

### 5. 💾 Сохранение и экспорт
- **Автосохранение:** все отметки и изменения сохраняются в `localStorage` вашего браузера и не пропадают при обновлении или перезагрузке.
- **Экспорт в Excel / CSV:** скачивание таблицы дежурств со сводными данными в формате `.csv` (с кодировкой UTF-8 BOM для корректного отображения в русском Excel).
- **Резервная копия (JSON):** возможность выгрузить файл резервной копии и загрузить его на другом компьютере или телефоне.
- **Печать / PDF:** кнопка для быстрой печати ведомости на принтере или сохранения в PDF.
- **Тёмная / Светлая тема:** кнопка переключения в шапке сайта.
